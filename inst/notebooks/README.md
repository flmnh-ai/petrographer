# Notebooks

This folder is split into three groups:

- `templates/`: current notebook templates that should stay close to supported package workflows
- `reference/`: useful working notes and maintainers-facing notebooks that are not treated as supported docs
- `archive/`: older project-specific training notebooks kept mainly as historical records for model-library runs

Current templates:

- `templates/model_from_pretrained.qmd`
- `templates/train_detection.qmd`
- `templates/train_segmentation.qmd`

Reference notebooks:

- `reference/model_zoo_pins.qmd`
- `reference/petrography_analysis.qmd`
- `reference/slicing_example.qmd`

Archived notebooks:

- `archive/training_inclusions.qmd`
- `archive/training_shell.qmd`
- `archive/training_shell_inclusions.qmd`
- `archive/training_background_removal.qmd`

Notes:

- These are not package vignettes.
- Some reference/archive notebooks intentionally contain stale or machine-specific details; mine them for ideas before treating them as current workflows.
